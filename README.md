# CDS-SH coding game

A coding education card-battle game set on the HKU CDS Shanghai campus. Built at the CDS-SH "Your campus, your game" hackathon, 2026-11-21.

- concept: [docs/overview.md](docs/overview.md)
- what's decided: [docs/decisions.md](docs/decisions.md)
- what's not: [docs/open-questions.md](docs/open-questions.md)
- prompts for building it: [prompts/](prompts/)
- raw material (meeting recording, transcripts, photos): [resources/](resources/README.md)

To work in it with Claude Code, clone the repo and run `claude` in the root. Read [CLAUDE.md](CLAUDE.md) first.

Audio and video are stored with Git LFS. Install it once (`git lfs install`) before cloning, or run `git lfs pull` afterwards.

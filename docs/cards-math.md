# MATH cards (arithmetic)

Whiteboard: "(arithmetic) MATH: + - x ÷ ^ log (mod)". Notes under it: "+/- heal / dmg" and "x / ÷ / ^ / log augmentation". Transcript 17:35 to 18:51.

| card | effect |
| --- | --- |
| `+` | **heal** (18:29) |
| `-` | **damage** (18:29) |
| `x` | augment: increases the current heal or damage. Example: +1, then x2, gives +2 (18:41 to 18:51) |
| `÷` | augment: decreases the current heal or damage (18:41) |
| `^` (power, exponential) | augment (board). Added at 17:40 |
| `log` | augment (board). Added as the inverse of `^`, "so all the inverse operations are there and things can cancel out" (17:52 to 18:01) |
| `mod` | written in brackets on the board, so tentative. "Mod is more of a math thing" (20:20 to 20:25). Effect not defined |

The design rule behind the set: every operation has its inverse in the deck, so plays can be cancelled out (17:56).

Open: rounding for `÷` and `log`; whether augments apply to your own last card or can target the opponent's; what `mod` does.

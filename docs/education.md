# education

Sources: part 1 23:14 to 24:15, part 2 05:41 to 07:00.

- The audience is **first-time visitors of any age**, not specifically parents (p2 06:17 to 06:25; hackathon brief 06:26).
- **The game should be intuitive for a first-time player regardless of age** (p2 06:35). **Keep the operations simple** (p2 06:30).
- It introduces basic coding concepts: **for loop, maybe while loop, if / else if / else**. Nothing too advanced (p2 06:41 to 07:00).
- **The first battle is a step-by-step tutorial**, like games have (p2 05:45 to 05:58). This covers the "tour" on the whiteboard.
- Present it as a coding education game, with an explanation and **worked examples** (23:42 to 24:01).
- The framing is "learning to code in CDS1, the same as being a CDS student" (24:10).
